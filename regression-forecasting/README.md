# Прогнозирование на основе регрессионного анализа

Дисциплина «Алгоритмизация и программирование», курсовая работа.

## Задача

Требуется разработать консольное приложение, которое по выборке
пар значений двух признаков строит уравнение линейной регрессии,
оценивает статистическую значимость модели и рассчитывает прогноз
результативного признака при заданном значении факторного признака.
Дополнительно строится доверительный интервал прогноза, что позволяет
судить о точности предсказания и его практической применимости.

## Исходные данные

Рассматриваются два набора данных.

Первый - синтетическая выборка из 200 наблюдений, сгенерированная
по линейному закону `y = 0.168 * x + 0.836` с гауссовским шумом.
Истинные коэффициенты заданы так, чтобы результат можно было сверить
с контрольным примером из курсовой работы.

Второй - открытый датасет `diamonds` из библиотеки `seaborn`,
содержащий 53940 наблюдений о бриллиантах. Исследуется зависимость
цены камня от его веса в каратах.

## Методология

Коэффициенты линейной регрессии вычисляются методом наименьших
квадратов через ковариацию и дисперсию факторного признака.
Коэффициент корреляции рассчитывается как нормированная ковариация,
коэффициент детерминации - как его квадрат. Значимость уравнения
в целом проверяется через критерий Фишера: эмпирическое значение
сравнивается с табличным при уровне значимости 0.05.

Для расчёта прогноза задаётся коэффициент, определяющий положение
точки предсказания относительно среднего значения факторного признака.
Например, коэффициент 1.1 означает, что прогноз строится для значения
на 10% выше среднего. Остаточная дисперсия оценивается по отклонениям
фактических значений от линии регрессии. Доверительный интервал
прогноза рассчитывается с учётом стандартной ошибки предсказания и
квантиля распределения Стьюдента с `n - 2` степенями свободы.

## Результаты

На синтетических данных уравнение приняло вид
`y = 0.175 * x + 0.783`, что близко к истинному `y = 0.168 * x + 0.836`.
Коэффициент корреляции составил 0.987, коэффициент детерминации 0.974.
Эмпирическое значение F-критерия многократно превышает табличное,
уравнение статистически значимо. Прогноз при значении факторного
признака на 10% выше среднего составил 2.774 при ошибке 0.146,
доверительный интервал `[2.486; 3.063]` признан статистически надёжным.

На датасете `diamonds` получено уравнение
`price = 7756.426 * carat - 2256.361`. Коэффициент корреляции 0.922,
коэффициент детерминации 0.85: вес камня объясняет около 85% вариации
цены, остальное приходится на качество огранки, цвет и чистоту.
Прогноз для камня весом 0.878 карата составил 4551.7 доллара
при ошибке 1548.6, доверительный интервал `[1516.5; 7586.9]`.
