# Статистический анализ на Python

Сборник учебных проектов по дисциплине «Алгоритмизация и
программирование». Каждый проект представляет собой консольное
приложение на Python, реализующее статистический метод без
использования готовых решений из специализированных библиотек:
расчёты выполняются вручную, через базовые математические операции.

Такой подход позволяет проследить логику каждого метода и понять,
что стоит за функциями библиотек вроде `scipy.stats` или `statsmodels`.

## Состав репозитория

### regression-estimation

Оценка параметров линейной регрессии по выборке пар значений.
Алгоритм включает предварительную очистку данных от выбросов по
правилу полуторного интервала, расчёт коэффициентов методом
наименьших квадратов, оценку тесноты связи через коэффициент
корреляции и проверку статистической значимости уравнения через
критерий Фишера.

Рассматриваются два набора данных: синтетический, сгенерированный
по заданному линейному закону с шумом и выбросами, и открытый
датасет `tips` из библиотеки `seaborn`.

[Перейти к проекту](regression-estimation/)

### regression-forecasting

Прогнозирование значения результативного признака на основе
регрессионной модели. Помимо оценки параметров уравнения, реализован
расчёт доверительного интервала прогноза с учётом остаточной
дисперсии и распределения Стьюдента.

Рассматриваются два набора данных: синтетический с известными
истинными коэффициентами и открытый датасет `diamonds` из библиотеки
`seaborn`, содержащий данные о бриллиантах.

[Перейти к проекту](regression-forecasting/)

### homogeneity-check

Проверка однородности совокупности значений признака для
интервальных рядов. Поддерживаются два формата входных данных:
отдельные значения и уже сгруппированные интервалы с частотами.
Рассчитываются коэффициент вариации, коэффициент осцилляции и
линейный коэффициент вариации.

[Перейти к проекту](homogeneity-check/)
